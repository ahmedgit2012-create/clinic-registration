# نظام تسجيل مرضى العيادة والحجز

تطبيق ويب (Node.js + Express + SQLite) بأربع واجهات لإدارة حجوزات عيادة.

## الواجهات

1. **السكرتير** (`/secretary`, تسجيل دخول مطلوب) — يسجّل حجوزات المرضى الحاضرين، موعد كل ربع
   ساعة، من الساعة 5:00 حتى 9:00 مساءً، كل الأيام ما عدا الأربعاء والجمعة.
2. **المريض** (`/patient`, بدون تسجيل دخول) — يدخل المريض بياناته ويحجز موعده إلكترونيًا
   (موعد واحد لكل ربع ساعة). يحصل بعد الحجز على **رمز مرجعي** يستخدمه للاستعلام عن حجزه أو
   إلغائه من `/patient/lookup` دون الحاجة لحساب.
3. **موظف النواظير** (`/endoscopy`, تسجيل دخول مطلوب) — يسجّل مرضى النواظير، حجز كل
   **ساعة كاملة** (5، 6، 7، 8 مساءً). موعد النواظير يتداخل مع الحجز العام: نفس اللحظة
   الزمنية (مثلاً 6:00) لا يمكن حجزها مرتين (لا كحجز عام ولا كحجز ناظور).
4. **المدير** (`/manager`, تسجيل دخول مطلوب) — يفتح جميع الواجهات الثلاث، يشاهد إحصائيات
   وجدول اليوم كاملاً، يستطيع إلغاء أي حجز، ويدير كلمات مرور حسابي السكرتير والنواظير من
   `/manager/accounts`.

لكل من السكرتير وموظف النواظير والمدير حساب مستقل (اسم مستخدم وكلمة مرور). واجهة المريض
عامة ومفتوحة للجميع دون كلمة مرور، لأنها مخصصة للمرضى أنفسهم.

## ميزات إضافية أضفتها

- **رمز مرجعي (Reference Code)** لكل حجز إلكتروني يقوم به المريض، مع صفحة استعلام/إلغاء ذاتية.
- **تحقق تلقائي** من عدم الحجز في الماضي، وعدم الحجز في يوم إغلاق (الأربعاء/الجمعة)، ومنع
  ازدواج الحجز على نفس الموعد (بقيد فريد على مستوى قاعدة البيانات لمنع التعارض حتى عند
  الحجز المتزامن).
- **لوحة إحصائيات** للمدير (عدد الحجوزات العامة، حجوزات النواظير، المواعيد الشاغرة).
- **تسجيل مصدر كل حجز** (سكرتير / المريض نفسه / موظف النواظير / المدير) لتتبع من قام بالحجز.
- واجهة عربية بالكامل (RTL) وتصميم متجاوب يعمل على الجوال.

## التشغيل

```bash
npm install
npm run seed     # ينشئ حسابات الموظفين الأولية (secretary / endoscopy / manager)
npm start
```

يعمل التطبيق افتراضيًا على http://localhost:3000

عند تشغيل `npm run seed` لأول مرة بدون تحديد كلمات مرور في ملف `.env`، ستُطبع كلمات مرور
عشوائية في الطرفية **مرة واحدة فقط** — احتفظ بها فورًا. يمكن لاحقًا للمدير تغيير كلمتي مرور
السكرتير والنواظير من واجهة إدارة الحسابات.

لتخصيص أسماء المستخدمين وكلمات المرور مسبقًا، انسخ `.env.example` إلى `.env` وعدّل القيم
قبل تشغيل `npm run seed`.

## البنية التقنية

- `server.js` — نقطة تشغيل التطبيق (Express + الجلسات).
- `src/db/index.js` — الاتصال بقاعدة بيانات SQLite وإنشاء الجداول.
- `src/db/bookings.js` — منطق الحجوزات (التحقق من القواعد، إنشاء/إلغاء الحجز، الجدول اليومي).
- `src/db/users.js` — إدارة حسابات الموظفين.
- `src/slots.js` — قواعد أوقات وأيام العمل.
- `src/routes/*` — مسارات كل واجهة.
- `src/views/*` — قوالب EJS لكل صفحة.
- `data/clinic.sqlite` — ملف قاعدة البيانات (يُنشأ تلقائيًا، غير مرفوع لنظام التحكم بالإصدار).

## ملاحظة حول جلسات المستخدمين

الجلسات محفوظة في الذاكرة (in-memory)، وهي كافية لتشغيل تطبيق بسيط على خادم واحد. عند نشر
التطبيق فعليًا لفترة طويلة أو على أكثر من عملية (process)، يُفضّل استخدام مخزن جلسات دائم
(مثل قاعدة بيانات) بدلاً من ذلك.
